# 科学计算器

一个功能完整的安卓科学计算器 App，使用 Kotlin + Jetpack Compose 开发。

## 获取 APK 的最快方法（无需安装任何软件）

1. 打开 https://github.com 并登录（免费注册一个）
2. 点右上角 **+** → **New repository**
3. 仓库名填 `ScientificCalculator`，点 **Create repository**
4. 把所有项目文件上传到这个仓库
5. 点 **Actions** 标签 → **构建 APK** → **Run workflow**
6. 等几分钟，下载 APK 文件
7. 传到手机上安装即可
